# dsh 人格卡 / proactive 插件素材来源

本目录是**素材源文件**，不参与编译，也不进 apk。
收拢目的是：内置人格卡包的正文与字段结构参考来自 dsh 生态的**开源插件**，
避免从零凭空写人设导致风格漂移。

## 许可与署名

- dsh 生态各仓库许可不一，逐条见下表。
- **MIT / Apache-2.0 / BSD-3-Clause**：可参考、可再创作，保留署名与许可声明即可。
- **NOASSERTION**：仓库未声明许可，**只做内部参考，不直接抄进产品**。
- 大肥鱼形象本身来自 `PC2005-cloud/dsh-pet`，素材**禁止商用**，二创须署名。

## 角色参考图（另一条线：形象一致性）

`artwork/refs/whale_girl/` —— 来自 [TreapGoGo/deepseek-whale-girl](https://github.com/TreapGoGo/deepseek-whale-girl)（★818, MIT），
社区共同维护的鲸鱼娘资源库。收集脚本：`tools/media/collect_whale_girl_refs.py`。

| 文件 | 用途 |
|---|---|
| `site__assets__dafeiyu-chibi-character-sheet.png` | **Q 版三视图**（正面 / 侧面 / 背面 + 局部特写）—— i2i 的唯一形象来源 |
| `site__assets__dafeiyu-mature-character-sheet.png` | 成熟版三视图 |
| `site__assets__workflows__comfyui-issue-2__*.json` | 6 份**固定 seed** 的 ComfyUI 工作流 |

- 三视图是「角色一致性靠参考图不靠文字描述」这条规则的现成落地物：
  拿三视图做 i2i 输入，比任何文字描述都准。
- 固定 seed 的工作流说明**同一 seed + 同一工作流 = 同一角色**，
  这是可复现生成的前提，比「每次重新抽一张」稳得多。

## 使用约束

1. **内置人格卡包直接采用这些仓库的人设正文**，不自己重写 —— 用户已明确要求
   「用高star仓库里别人写好的」。MIT / Apache-2.0 需保留署名与许可声明。
2. **只从 MIT / Apache-2.0 / BSD-3-Clause 仓库取正文**。
   NOASSERTION（`linsport`、`Britneycode`、`Yuuyuko-uu`）仅供内部参考，不进产品。
3. `MisakaZentai/dsh-persona-presets` 的人格文本源自轻小说《我的妹妹哪有这么可爱！》，
   **同人性质、非商用**，且角色是黑猫/猫娘/吸血鬼 —— 不是大肥鱼，不进产品。
4. `wxzjss/dsh-whale-loli` 的 `persona-v3-naughty.md` 含成人向内容，**排除**。
5. 字段结构（哪些字段、怎么分层）沿用 dsh 的设计，这属于方法论，不涉及抄袭。
