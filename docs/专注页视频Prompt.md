# 专注页视频 Prompt 包（1 段 · 9:16）

DeepFocus 大肥鱼专注陪伴 App

> **为什么只剩这一段视频**
>
> 原来的 9 段视频（登场 / AI 串门 / 换装 / 专注页）已全部取消制作。
> 登场、喂食、换装改用 dsh-pet 的一百多个透明 GIF 动作库
> （[仓库](https://github.com/PC2005-cloud/dsh-pet)），转码成 animated WebP，
> 体积小、动作多、随装随用。
>
> **只有专注页书房还用视频** —— 它要 9:16 全屏铺满、
> 要有环境音（翻书、鸟鸣、笔尖沙沙），
> GIF 撑不起这种沉浸感，而且全屏放大会把小图拉糊。

| 项 | 值 |

| 首尾帧 | **不传** |

> 上方留出大片干净的天空/墙面 —— **计时器要浮在那儿**，
> 主角不能占满画面，否则数字压在脸上。

## 怎么用

1. 豆包 / 即梦 → 视频生成 → 选**图生视频**
2. 上传对应的参考图（**只传 1 张**）
3. 复制该段的 prompt，一个字都不要改
4. 参数：时长 20 秒、1080P、9:16、**不传首尾帧**
5. 下载后改名，放进 `DeepFocus/artwork/videos/focus/`：
   - `bigfatfish.mp4`（常服）
   - `bigfatfish_winter.mp4`（冬装，可选 —— 没有就退回常服版）
6. 跑安装脚本：

```bat
python tools\media\install_videos.py
```

> 安装脚本会：压缩到 H.264 baseline + yuv420p（Android 兼容）→
> 叠一层环境音（`tools/media/ambience.mp3`，首尾各淡入淡出 0.3 秒，
> 循环时不爆音）→ 装进 `app/src/main/assets/videos/focus/`。

## 验收标准

出片后对着这几条看一眼，不合格就重出：

- [ ] 大肥鱼在**画面下方**，上方留白够放计时器（至少 40% 高度是空的）
- [ ] 角色形象和参考图一致（深蓝发、女仆装、深蓝鱼尾、头顶呆毛）
- [ ] 动作是**看书 + 小动作**，不是大幅走动（大幅动作在循环里会很晕）
- [ ] 整体**安静**，没有夸张表情（专注页要的是「陪着你」的感觉）
- [ ] 首尾帧的**镜头和背景几乎一致**（要能无缝循环）
- [ ] 没有文字、字幕、水印
- [ ] 冬装版有雪/冷色调，但角色五官和常服是同一个人
