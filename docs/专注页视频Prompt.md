## 旅游版（当前主用 · 慢火车靠窗）

**为什么选「移动中的窗」**

专注页的视频不是 MV，是背景。它要满足三件事：**低频运动、无叙事、能无缝循环**。
「车窗」天然满足前两条 —— 车外风景负责「在路上」的感觉，
车厢内几乎静止，形成「动中有静」；窗框还顺手把画面切成两层：
上层干净留白给计时器，下层坐角色。

不要出现电线杆、树列这类高频重复物 —— 循环接缝会明显「跳」一下。
让窗外以**大块、低对比、慢速**的田野、远山、海平线、云为主。

**参数**：

| 项 | 值 |
|---|---|
| 模式 | 图生视频（只传 1 张参考图） |
| 比例 / 分辨率 | 9:16 · 1080×1920 |
| 时长 | 20 秒最佳；只能出 5/10 秒也行，播放器会循环 |
| 帧率 | 24 或 30fps |
| 运动幅度 | **小 / 低**（即梦选「运动幅度小」，可灵选低动态） |
| 首尾帧 | 不传；若模型支持单独设尾帧，可把同一张参考图设为尾帧强制闭环（要求同时设首帧的就一起设） |
| 落地文件名 | `bigfatfish.mp4` |

**循环要点**：

- 出片后掐掉首尾各 0.2–0.3 秒的「起手/收势」帧，再接循环，接缝最不明显。
- 首尾帧构图差异越小越好；靠「身体不动 + 风景极慢」把接缝藏掉。
- 声音：不需要。安装脚本会去掉音轨，App 内也强制静音。

**验收标准（旅游版）**：

- [ ] 上方至少 40% 高度是干净的，能放下计时器
- [ ] 角色形象与参考图一致（深蓝发、常服、深蓝鱼尾、头顶呆毛）
- [ ] 镜头完全不动，没有推拉摇移
- [ ] 只有眨眼、发丝、窗帘、热气、尾尖这类微动效，没有大幅动作
- [ ] 首尾帧几乎一致，循环播放看不出接缝
- [ ] 没有文字、字幕、水印
- [ ] 光线暖而不刺眼，画面不抢注意力

### B. 海边露营（篝火夜景）

篝火是天然的循环素材（火焰、火星、烟雾都在周期性运动），
循环接缝几乎无感，比横向风景更好做。


## 怎么用

1. 豆包 / 即梦 → 视频生成 → 选**图生视频**
2. 上传对应的参考图（**只传 1 张**）
3. 复制该段的 prompt，一个字都不要改
4. 参数：时长 20 秒、1080P、9:16、**不传首尾帧**
5. 下载后改名，放进 `DeepFocus/artwork/videos/focus/`：
   - `bigfatfish.mp4`（常服）
   - `bigfatfish_winter.mp4`（冬装，可选 —— 没有就退回常服版）
6. 跑安装脚本：

```bat
python tools\media\install_videos.py
```

> 安装脚本会：压缩到 H.264 baseline + yuv420p（Android 兼容）→
> 去掉音轨（专注页不播任何声音）→ 装进 `app/src/main/assets/videos/focus/`。

## 验收标准

出片后对着这几条看一眼，不合格就重出：

- [ ] 大肥鱼在**画面下方**，上方留白够放计时器（至少 40% 高度是空的）
- [ ] 角色形象和参考图一致（深蓝发、女仆装、深蓝鱼尾、头顶呆毛）
- [ ] 动作是**看书 + 小动作**，不是大幅走动（大幅动作在循环里会很晕）
- [ ] 整体**安静**，没有夸张表情（专注页要的是「陪着你」的感觉）
- [ ] 首尾帧的**镜头和背景几乎一致**（要能无缝循环）
- [ ] 没有文字、字幕、水印
- [ ] 冬装版有雪/冷色调，但角色五官和常服是同一个人
